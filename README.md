# InstaVid — Instagram Video Downloader

**Live site: [https://instavid.online](https://instavid.online)**

Download Instagram videos quickly and easily — no login required. Paste any Instagram post or reel URL and download the video directly to your device.

## Features

- Paste an Instagram post or reel URL and fetch video info instantly
- One-click video download
- Displays video title, uploader, duration, and thumbnail
- No account or login required

## Tech Stack

- [Next.js](https://nextjs.org) (App Router)
- [React](https://react.dev)
- [Tailwind CSS](https://tailwindcss.com)
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) via [youtube-dl-exec](https://github.com/nicholasgasior/youtube-dl-exec)
- [ffmpeg-static](https://github.com/eugeneware/ffmpeg-static)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
